Reliable WooCommerce order webhooks with delivery logs and retry queue (Pro).

== Description ==

Send JSON payloads to your endpoint when orders are created or change status.

Free: 1 endpoint + delivery log
Pro: multiple endpoints, retry queue, filters

== Installation ==

1. Install and activate WooCommerce.
2. Activate Order Webhook Hub.
3. WooCommerce → Order Webhook Hub → paste webhook URL.
