Fast WooCommerce CSV export and import for bulk product updates.

== Description ==

Export up to 500 products to CSV and re-import updates by ID or SKU.

Pro adds diff preview, variation sync, and scheduled jobs.

== Installation ==

1. WooCommerce → Bulk Product Sync
2. Export CSV, edit, re-import
